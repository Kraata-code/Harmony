# Política de seguridad

## Reportar una vulnerabilidad

No abras un issue público para informar de una vulnerabilidad. Usa el formulario
privado de [GitHub Security Advisories](https://github.com/Kraata-code/Harmony/security/advisories/new)
e incluye la información necesaria para reproducir y evaluar el problema.

El propietario del repositorio debe habilitar la opción **Private vulnerability
reporting** en GitHub para que este formulario esté disponible.

Si el formulario no está disponible, contacta de forma privada con los
mantenedores a través de [GitHub](https://github.com/Kraata-code), sin publicar
detalles técnicos sensibles.

## Información recomendada

- Descripción del problema y su impacto.
- Pasos para reproducirlo o una prueba de concepto segura.
- Versiones, ramas, dispositivos y configuraciones afectadas.
- Posibles mitigaciones, si las conoces.
- Tu información de contacto y el crédito que prefieras recibir.

No incluyas contraseñas, tokens, claves privadas ni datos personales que no sean
necesarios para investigar el reporte.

## Versiones con soporte

| Rama o versión | Estado |
|---|---|
| `dev` | En desarrollo y con soporte |
| Última versión publicada | Con soporte mientras sea la versión actual |
| Versiones anteriores | Sin soporte garantizado |

Los tiempos de respuesta dependen de la gravedad, la información proporcionada
y la disponibilidad de los mantenedores. Las vulnerabilidades confirmadas se
coordinarán mediante GitHub Security Advisories antes de su divulgación pública.
